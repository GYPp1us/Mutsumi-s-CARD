# md2svg 绘图重构实施与完成审计

## 范围

以用户 2026-09-15 的最新要求替代旧规范中 Markdown 不可移动、不可缩放的限制。使用 GYPp1us/md2svg Rust SDK，保留 Android 原生 Compose、双面 PNG 保存、图层顺序和独立无限世界相机。

## 实施

1. 固定 SDK 提交 `91cf197ea5fb082dceeb09abc746712c9b670eca`，JNI 桥接长期复用 Renderer，resvg 负责透明像素输出；保留最近两份 SVG 排版缓存，拖动只重新栅格化。
2. Markdown 位移使用 1024×1624 卡面坐标；双指张开降低 SDK 宽度，从而放大字号并重新换行。宽度遵循 SDK 的 64–4096 范围；小幅手势保留浮点累积。
3. 预览后台串行、合并过期请求；保存锁定草稿并等待准确的最终宽度与位移渲染。所有调用方迁移到同一渲染器。
4. 绘图工具与卡面边界复用单实线（绘制）、虚线（Markdown）、双线（底图），提供中文标签和触控入口；整理工具区和卡面标题。
5. 完整构建并发布下一版本 v0.8.0（versionCode 27），验证历史签名、APK 附件与覆盖安装。
