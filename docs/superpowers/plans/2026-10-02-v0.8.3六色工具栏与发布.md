# v0.8.3 六色工具栏与发布

## 行为与范围

- 收起绘图右侧属性栏后，六个预设色块直接纵向显示，保留自定义 RGB 入口。
- 展开时三列两行显示同一组预设色：墨绿、珊瑚红、蓝灰、金黄、紫色、墨黑。
- 选中色使用描边和选中语义；锁定、解锁与工具切换保留选中色。
- 短屏纵向滚动，固定解锁和保存入口，保持双面画布释放的空间。
- 发布 0.8.3/versionCode 30，沿用历史签名和三个架构包及通用包。
