# v0.10.0 卡片管理与安全同步

## 目标与裁决

按用户最新要求重构管理及备份，版本 0.10.0 / 32。在原取证提交上新建 `codex/v0.10.0-library-sync`，沿用当前隔离工作区，不修改主工作区。真实恢复材料与内容映射只在忽略目录保存。

卡组作为可嵌套的文件夹，每层可包含卡组和卡片。支持面包屑、搜索、多选、全选、移动、复制、归档/恢复及删除。批量操作必须原子提交，禁止把父卡组移入后代；删除先列出影响数量并确认。

## 四个严格语义

| 操作 | 来源 | 目标 | 允许改动 |
| --- | --- | --- | --- |
| 增量拉取 | 云端 | 本地 | 新增、更新；保留本地独有记录 |
| 增量推送 | 本地 | 云端 | 新增、更新；保留云端独有记录；绝不反写本地 |
| 拉取删除 | 云端 | 本地 | 仅删除本地独有记录，不新增更新 |
| 推送删除 | 本地 | 云端 | 仅删除云端独有记录，不新增更新 |

四个操作全部先预览。前两个使用同级按钮，后两个在预览页滑动二次确认。方向决定同 ID 内容取舍，更新的详细前后差异在预览中可见，时间戳不作为删除或冲突裁决依据。若用户对删除语义给出不同选择，再调整此表。

预览绑定配置身份、本地数据库修订号和云端索引版本。执行前再次检查，数据库提交在同一事务内检查修订号。失效预览不能执行。删除不以三方基线自动推导。首次空源删除须明确显示全部影响；空云端未建立索引时禁止拉取删除。

## 数据与索引

- Room 升级保存卡组父级和归档状态；修订表及触发器覆盖卡组、卡片、复习状态的所有写入。
- 单一私有索引缓存完整元数据、卡组统计及图片路径/哈希；修订号不变时直接复用。图片路径不可变，仅对新路径读取和计算哈希。
- 云端使用独立的 `library-index.json`（格式 3）缓存当前完整元数据、卡组统计和历史版本摘要，一次读取获得状态。新对象与快照位于 `library-v3/objects` 和 `library-v3/snapshots`，旧客户端清理不能波及新资料库。首次兼容读取旧索引与其当前快照，不写回旧索引。
- PNG 继续按内容哈希复用。预览不下载图片，按页渐进呈现变更与创建/更新时间、卡组、归档状态、复习次数、双面、字节数及短 ID。执行仅传输缺失图片，显示阶段、对象数和字节进度。
- 云端先上传不可变对象及快照，最后获取原子目录锁，在锁内核对预览时索引的内容哈希，再发布并回读；失败不修改本地。不依赖服务器条件请求头。拉取前保存本地完整安全副本；图片验证后事务提交；预览后并发写入必须拒绝提交。
- 本地 ZIP 导入/导出保留层级、归档卡及真实时间/复习状态；导入始终新副本，不遗漏归档记录。

## 十张卡片恢复

保全旧索引、历史快照与全部 PNG。把用户确认的十张背面卡片加入云端新索引，按确认的中文 key 和分配关系进入两个原有目标卡组，保留既有 31 张，不创建重复卡组。采用稳定、幂等恢复 ID，复习状态未学习、权重 1。时间标明重建时间，不伪造原时间。实际内容映射保存在私有交付目录，不进入公开提交。

实际云端发布前先以应用解析器验证新格式和 41 张卡；确认旧索引仍与取证基线一致，在目录锁内核对并禁止覆盖已有不同的新索引；发布后重新下载校验。凭据仅交互进入内存，不进仓库、输出、截图或命令行参数。
