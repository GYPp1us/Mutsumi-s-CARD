# v0.8.2 专注上报实施与验收

## 行为

- 设置中输入个人 408 Dashboard 目录链接或密钥；从服务端目录读取科目与事项，按数字 ID 配对。目录当前包含 408 科目 ID 1，强化 ID 9、二轮 ID 1、模拟 ID 5。
- 使用者确认事项并启用后，前台学习页存在卡片时立即发送 focus，随后每 20 秒续报。固定来源 `mutsumi_card`，不发送客户端时间。
- 离开学习页、关闭开关、进入后台时立即发送 idle；网络断开由服务器 45 秒超时兜底。409 暂停心跳并提示并发专注或当日已结算。
- 密钥经 Android Keystore AES-GCM 加密，文件存于 noBackupFilesDir；科目、事项 ID 和开关存于 DataStore。密钥不进入源码、构建、日志或备份。
- 发布 0.8.2/versionCode 29，沿用历史签名、架构拆包和通用 APK。
