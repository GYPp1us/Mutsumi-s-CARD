# v0.8.1 收起属性栏与包体优化

## 交付范围

- key 锁定后，属性栏在 260ms 内收至 64dp；释放宽度由正反面等分，卡面仍按 ISO ID-1 比例适配。
- 解锁、保存固定在工具轨两端；文档、底图、颜色与笔宽使用纵向控件。窄栏状态反馈通过 Snackbar 展示。
- 解锁保留 key、两面内容、相机与文档变换。锁定时清除焦点以关闭输入法。
- 发布三个架构 APK 和旧更新器需要的通用 APK，新更新器优先选择设备支持的架构包。
- R8 裁剪未使用代码和资源；压缩原生库；完全相同的许可证正文只保存一次，各依赖保留引用。
- 不改变 SDK 锁定提交及字体集合。继续使用历史签名、应用 ID 和 versionCode 28。

## 资源与等待策略

本地复用上一版本未变更的 Rust 原生库，CI 按 Cargo.lock 编译验证。修改集中完成后提交一次 CI；缓存构建先等待约 15 分钟，若仍运行则延长检查间隔。冷构建预计约 40 分钟时，约一小时后检查。
